# 樱花工作台 · 设计说明

面向「家教中间人」的个人工作台。核心命题不是记账，而是**同时管理两条关系链**：
对家长你是「负责的老师/顾问」，对老师你是「派单方」，而真正属于你的收入是中间那一层差价。
所有设计都围绕这一点展开。

---

## 一、界面布局建议

### 1. 整体框架：左导航 + 主内容区

```
┌──────────┬────────────────────────────────────────────────┐
│  品牌区   │  页面标题 / 副标题        今日日期  [快速新建]  │
│──────────┼────────────────────────────────────────────────┤
│ 仪表盘    │                                                │
│ 智能待办 3│                                                │
│ ──教务──  │              主内容区（卡片式）                 │
│ 学员档案  │                                                │
│ 可视化课表│                                                │
│ 财务统计 *│   * 家长视角下整项从导航中消失                   │
│ ──辅助──  │                                                │
│ 常用话术  │                                                │
│ 设置      │                                                │
│──────────│                                                │
│ 视角切换卡│                                                │
└──────────┴────────────────────────────────────────────────┘
```

**为什么把「视角切换」放在左下角固定位置**：这是每天要用很多次的开关（家长坐在旁边看课表时必须一键切走），
放顶部容易误触，放设置里又太深。固定在侧边栏底部，带颜色区分（粉色=后台，蓝色=家长视角），
切换后底部还会有一条常驻提示条，避免忘记自己处在哪个模式。

### 2. 各页面布局

| 页面 | 布局 | 设计要点 |
|---|---|---|
| 仪表盘 | 欢迎条 + 4 个指标卡 + 左右双栏 | 左栏放"今天要上的课"时间线，右栏放"今天要做的事"，一屏看完当天。异常项（时间重叠、试课待回访、遗留待办）用彩色标签顶在最上方 |
| 智能待办 | 左 2/3 任务区 + 右 1/3 模板库 | 模板库常驻右侧，一键导入，杜绝重复输入。四象限用左侧色条区分，已完成折叠成一行归档 |
| 学员档案 | 状态 Tab + 搜索 + 卡片瀑布流 | 卡片而非表格——每个学员是"一个人"而不是"一行数据"，备注（家长性格）要能一眼看到 |
| 可视化课表 | 工具条 + 周/月/年三视图切换 | 周视图是主力（时间轴 + 拖拽），月视图看密度，年视图看淡旺季 |
| 财务统计 | 区间选择器 + 4 指标卡 + 图表区 + 明细表 | 三本账（家长流水 / 老师课酬 / 我的抽成）永远并排出现，避免只盯流水产生错觉 |
| 常用话术 | 分类 Tab + 卡片网格 | 按"对家长/对老师"分色，一键复制并统计使用频次，高频自动前置 |

### 3. 视觉规范

- 主色 `#f9709d`（樱花粉）／辅助 `#ffb6ce`／背景 `#fff8fb`，深色文字 `#4a2c3c` 保证可读性
- 全局飘落樱花（22 片，透明度 0.35~0.8，不遮挡点击）
- 学科色板固定：数学粉、语文绿、英语蓝、物理金、化学紫……课表上靠颜色就能认出科目
- 金额一律等宽数字（`tabular-nums`），避免跳动
- 内部数据统一挂 `.secret` class，家长视角一次性隐藏，不需要在每个组件里写判断

## 二、数据字段设计

### 1. 学员档案 Student —— 中间人模式的核心

编码格式：`[签约日期]-[年级学科]-[家长称呼]-[抽成]/[课时费]|[课时长]`
例：`240815-高二数学-李妈妈-50/300|90`

| 字段 | 类型 | 来源 | 说明 |
|---|---|---|---|
| `id` | string | 系统 | 唯一标识 |
| `code` | string | 输入 | 原始编码，规范化后回写 |
| `signDate` | date | **解析** | 支持 YYMMDD / YYYYMMDD |
| `grade` | string | **解析** | 从「高二数学」中拆出「高二」 |
| `subject` | string | **解析** | 拆出「数学」，决定课表配色 |
| `parentName` | string | **解析** | 对外称呼 |
| `commission` | number | **解析** | **我每节课的抽成（内部）** |
| `tuition` | number | **解析** | **家长每节课支付（对外）** |
| `duration` | number | **解析** | 分钟，决定课表卡片高度 |
| `teacherCost` | number | *推导* | = `tuition - commission`，不存储，避免三处数据打架 |
| `teacherId` | string | 选择 | 关联老师 |
| `studentName` | string | 选填 | 孩子姓名 |
| `status` | enum | 选择 | `trial` 试课中 / `active` 在读 / `paused` 暂停 / `ended` 结课 |
| `trialDate` | date | 选填 | 试课日期，**次日自动生成回访待办** |
| `note` | text | 选填 | 家长性格、特殊要求、孩子薄弱点 |

> 设计取舍：抽成用**绝对金额**而不是百分比。实际业务里同一个老师不同单子的分成经常是拍脑袋定的，
> 存百分比会在改价时产生小数误差；存金额，比例由系统实时算给你看。

### 2. 课程 Lesson —— 价格快照

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` / `studentId` / `teacherId` | string | 关联 |
| `date` | date | 上课日期 |
| `start` | time | 开始时间，配合 `duration` 计算结束时间与冲突 |
| `duration` | number | 分钟 |
| `tuition` | number | **成交时的课时费快照** |
| `commission` | number | **成交时的抽成快照** |
| `status` | enum | `scheduled` 待上课 / `done` 已完成 / `cancelled` 取消请假 |
| `note` | text | 课堂反馈，转述给家长的原始素材 |

> 关键设计：课程**冗余存储价格**而不是每次去学员表取当前价。
> 涨价、换老师、调整分成之后，历史账目不会被改写——这是财务统计可信的前提。

### 3. 待办 Todo / 模板 Template

| Todo 字段 | 说明 |
|---|---|
| `title` / `note` | 内容 |
| `priority` | 0 紧急重要 / 1 重要不紧急 / 2 紧急不重要 / 3 都不 |
| `tag` | 日常 / 家长沟通 / 财务 / 拓客 / 试课跟进 |
| `date` | 归属日期，支持"把遗留任务一键拉到今天" |
| `done` / `doneAt` | 完成状态与时间，用于归档区 |
| `tplId` | 来源模板，用于**同一天不重复导入** |
| `autoKey` | 自动任务幂等键，如 `trial:{学员id}:{试课日}`，保证系统不会反复生成同一条回访 |
| `studentId` | 关联学员，待办上直接显示是谁 |

### 4. 老师 Teacher / 话术 Phrase

- Teacher：`name` / `phone` / `note`，统计维度用（谁带的课最多、课酬支出多少）
- Phrase：`cat`（parent / teacher / common）、`title`、`content`、`hits` 使用次数，高频自动排前

## 三、角色隔离机制（重点）

系统里同一笔业务被拆成**三个金额**，永远同时存在、永远不混：

```
家长流水 gross  =  Σ tuition        ← 对外，家长视角唯一可见的钱
老师课酬 cost   =  Σ (tuition - commission)   ← 对内，成本
我的抽成 profit =  Σ commission      ← 对内，真实利润
恒等式：gross = cost + profit
```

**双视角实现**：
- 后台模式：三本账全部展示，财务菜单可用，课表卡片上直接标"抽 50"
- 家长视角：`.secret` 元素整体隐藏、财务菜单消失、课表只剩课时费、月视图金额切换为流水口径

**统计口径**：默认只算 `status = done` 的课程（钱到手才算数），可勾选「含未上课程」查看预计收入；
取消/请假的课永远不计入。区间支持本月 / 上月 / 近 30 天 / 本年 / 任意自定义起止日期，并自动算环比。

## 四、几条业务规则

1. **冲突不拦截，只提示**。同一时间允许排两节课（你并不亲自上课），重叠的课在周视图里自动并排、
   加红框和红点，拖拽后会 toast 告知重叠数量。
2. **试课回访幂等**。学员标记 `trial` 并填试课日期后，次日打开工作台自动生成一条紧急待办
   「回访 XX 妈妈试课体验」，靠 `autoKey` 保证只生成一次，删掉也不会再冒出来。
3. **模板不自动产生任务**。模板库只有你点「一键导入」才会落到当天，否则会堆成一片死任务。
   同一天同一模板不会重复导入。
4. **数据全本地为主**。默认存 localStorage，不上传任何服务器；设置页可导出 JSON 备份 / 导入恢复。
   若开启云同步，数据会先在本机用 AES 加密（密钥由 Token 生成）再上传到你的私密 Gist，明文绝不出本机。

## 五、后续可扩展方向

- 课时包与余额：给 Student 增加 `packageTotal` / `packageUsed`，剩余不足 3 次时自动生成催费待办
- 收款状态：给 Lesson 增加 `paid` 与 `settled`（家长是否已付 / 老师是否已结），做成两条独立的对账流
- 家长分享页：导出只含课表和课时费的只读链接，进一步减少手滑风险
- 老师端简报：按老师和日期区间导出课酬结算单
